# Data dictionary

Generated by `notebooks/02_data_preparation.ipynb` from the column comments in `sql/02_clean.sql` and `sql/03_revenue_cube.sql`. Do not edit by hand. Raw tables mirror the CSVs in `data/raw/`; see `docs/data_profile.md`.

## clean_customers

One row per customer. Source: raw_customers plus subscription-derived fields.

| column_name | data_type | description |
| --- | --- | --- |
| customer_id | VARCHAR | Customer key from the data room. |
| customer_name | VARCHAR | Customer name exactly as supplied. |
| customer_name_std | VARCHAR | Tidied display name: spaces collapsed, trailing punctuation removed, Limited to Ltd, Grp to Group, "and" to "&". |
| name_key | VARCHAR | Upper-case matching key from customer_name_key(); used to find ids that share a name. |
| name_collision_flag | BOOLEAN | TRUE if another customer_id has the same name_key (Q01). Ids are not merged. |
| signup_date | DATE | Signup date as supplied. |
| signup_month | DATE | First day of the signup month; cohort month 0. |
| signup_year | BIGINT | Calendar year of signup_date. |
| signup_quarter | VARCHAR | Signup quarter label, e.g. 2023Q2; the cohort key. |
| is_pre_window | BOOLEAN | TRUE if the customer signed up before January 2022 (left-censored in the invoice data). |
| tenure_months_at_dec_2025 | BIGINT | Whole months from signup_month to December 2025. |
| industry | VARCHAR | Industry; Unknown where the source is blank. |
| industry_missing_flag | BOOLEAN | TRUE if industry was blank in the source. |
| region | VARCHAR | Region as supplied (ten UK regions, three EU countries). |
| region_group | VARCHAR | UK or EU (EU where region ends "(EU)"). |
| company_size | VARCHAR | Size band as supplied. |
| acquisition_channel | VARCHAR | Acquisition channel as supplied. |
| account_manager | VARCHAR | Account manager as supplied. |
| first_subscription_start | DATE | Earliest subscription start_date for the customer. |
| last_subscription_end | DATE | Latest non-blank subscription end_date (NULL if no line has ended). |
| has_active_subscription | BOOLEAN | TRUE if any subscription line has a blank end_date. |
| is_large_account | BOOLEAN | TRUE if any subscription line is priced at 10x list price or more. |

## clean_invoices

One row per billing event after removing the 40 duplicate copies (A01).

| column_name | data_type | description |
| --- | --- | --- |
| invoice_id | VARCHAR | Invoice or credit-note key (INV or CN prefix). |
| customer_id | VARCHAR | Customer key. |
| product_id | VARCHAR | Product key. |
| product_line | VARCHAR | Product line from clean_products. |
| invoice_date | DATE | Invoice date as supplied. |
| month_start | DATE | First day of the invoice month; the revenue month. |
| revenue_type | VARCHAR | recurring or one-off (matches the product on every row). |
| status | VARCHAR | paid, overdue or credited. |
| amount | DECIMAL(14,2) | Amount in £ as supplied; credit notes are negative. |
| is_credit_note | BOOLEAN | TRUE for status credited. |
| credit_note_original_id | VARCHAR | For a credit note, the invoice it reverses (same customer, product, date and absolute amount). |
| credited_by_id | VARCHAR | For an invoice that has been reversed, the credit note that reverses it. |
| anomaly_flag | BOOLEAN | TRUE for a negative amount on an invoice marked paid or overdue (P06). |
| amount_as_reported | DECIMAL(14,2) | P06 candidate: amount as supplied. |
| amount_flipped | DECIMAL(14,2) | P06 candidate: sign reversed on anomaly rows, otherwise amount. |
| amount_excluded | DECIMAL(14,2) | P06 candidate: zero on anomaly rows, otherwise amount. |
| oneoff_category | VARCHAR | For one-off invoices: signup_implementation (billed in the signup month) or other_implementation. NULL for recurring. |
| before_signup_flag | BOOLEAN | TRUE if invoice_date is before the customer signup_date (always the same calendar month). |
| is_overdue | BOOLEAN | TRUE for status overdue. Kept in revenue; reported separately for working capital. |

## fact_revenue_monthly

One row per customer x product x month with any billing or credit. Grain key: customer_id, product_id, month_start.

| column_name | data_type | description |
| --- | --- | --- |
| customer_id | VARCHAR | Customer key (dim_customer). |
| product_id | VARCHAR | Product key (dim_product). |
| month_start | DATE | Revenue month (dim_date). |
| product_line | VARCHAR | Product line. |
| revenue_type | VARCHAR | recurring or one-off. |
| gross_billings | DECIMAL(14,2) | Sum of invoices other than credit notes, under the current anomaly setting. |
| credit_notes | DECIMAL(14,2) | Sum of credit notes (negative). |
| net_revenue | DECIMAL(14,2) | gross_billings + credit_notes. |
| recurring_net | DECIMAL(14,2) | net_revenue on recurring products. |
| oneoff_net | DECIMAL(14,2) | net_revenue on one-off products. |
| oneoff_signup_net | DECIMAL(14,2) | One-off revenue with oneoff_category signup_implementation. |
| oneoff_other_net | DECIMAL(14,2) | One-off revenue with oneoff_category other_implementation. |
| anomaly_amount | DECIMAL(14,2) | Amount of P06 anomaly rows included under the current setting. |
| overdue_amount | DECIMAL(14,2) | Billings with status overdue (included in net_revenue). |
| invoice_count | BIGINT | Number of invoices other than credit notes. |
| credit_note_count | BIGINT | Number of credit notes. |
